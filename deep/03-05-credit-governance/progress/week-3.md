# 3주차 진행 (10/26~10/31)

1. 한 일: L4 보고서에 종류가 다른 함정 8개를 심고(정답표는 저장소 밖, 해시만 커밋), 같은 지시문으로 엔진 3개(Claude·DeepSeek·Qwen)가 검토하고 Gemini가 결과를 비교함. 정답표로 채점(Claude 8 · DeepSeek 6.5 · Qwen 2.5 / 8)하고 엔진 선택 규칙과 L6 클라이언트 메모를 씀. 최종 판정은 조건부 Go.
2. 확인한 것: 정답표를 열어 T1~T8 채점을 줄마다 대조함. 엔진 주장도 L3 원자료로 다시 확인해, DeepSeek의 오지적 2건(R02 8명, 고용 인원)과 Qwen이 입력에 없는 연령 데이터를 지어낸 것을 찾아냄.
3. 발견: 비교 엔진(Gemini)은 결과끼리만 비교해서 Qwen이 지어낸 숫자를 "타당"으로 받아들임 → 비교 엔진에는 원자료도 같이 줘야 하고, 진위 판정은 사람이 해야 함. ChatGPT는 파일이 없을 때 지어내지 않고 "확인 불가"라고 답함.
4. 막힌 점: ChatGPT(파일 첨부 실패·무료 한도), Trae(정답표가 있는 다운로드 폴더를 열라고 해서 중단, 이후 무료 한도), Kimi(접속 불가) → 웹 엔진으로 바꾸고 입력을 한 파일 붙여넣기로 통일함.
