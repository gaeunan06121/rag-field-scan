# L1·L2 — 규제 카드와 요구사항 표 지시문 (10/17, 사후 정리)

- 엔진: Claude (웹 검색 사용)

## L1
V뱅크(가상 디지털은행)가 신용 이력이 짧은 청년에게 대안 데이터로 신용점수를 매기는 모델을 출시하려 한다.
이 모델에 적용되는 규제를 EU·홍콩·한국 원문 기준으로 카드 12장 이상 만들어 줘.
카드마다: 문서명, 조항 번호, 원문 링크, 한두 줄 요약, V뱅크 시사점, 원문 대조 여부(☐/☑).
확인하지 못한 내용은 지어내지 말고 "확인 필요"로 표시해.
내가 직접 원문 대조할 카드 5장을 골라 체크리스트로 줘.

## L2
L1 카드를 근거로 요구사항 표를 15개 이상 만들어 줘.
분류: 설명 · 공정성 · 데이터 · 사람의 감독 · 모니터링 · 기록.
열: ID, 분류, 요구사항, 근거 카드, V뱅크가 해야 할 일, 증빙 자료.
(10/23 추가 요청) "관할", "관할 간 차이" 열을 더해 줘.
