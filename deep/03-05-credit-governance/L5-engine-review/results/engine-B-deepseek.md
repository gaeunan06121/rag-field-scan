## 2. 확인하지 못한 것
- 성별·연령대별 신청자 구성과 승인·거절 수치: L3 결과·스코어카드에 해당 변수가 없어 확인 불가
- §3 민감도 재계산(V7·V8·V9 제거, 판정선 570/530 적용) 결과: 재계산 표·스크립트 출력이 붙여넣은 자료에 없어 확인 불가
- R09 "정정·삭제·재산출 절차 운영 중"의 실제 운영 여부: V뱅크 자료는 "자료 미제출"이라 확인 불가
- R17 "로그 1년 보관": V뱅크 자료는 "3개월 후 삭제"라 1년 보관은 확인 불가(오히려 반대)
- 한국 신용정보법상 대안 데이터 신용평가 동의 조항: L2가 "카드 미작성"이라 명시해 확인 불가
- AI 기본법 시행(2026.1.22) 대비 현재 시점·계도기간: 자료에 날짜 기준이 없어 확인 불가
