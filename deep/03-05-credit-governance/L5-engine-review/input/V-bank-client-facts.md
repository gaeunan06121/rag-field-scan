# V뱅크 의뢰 자료 요약 (가상)

> 실사의 근거가 되는 **가상 클라이언트 제출 자료**예요. L4 판정은 이 자료에 적힌 것만 근거로 해요. 적혀 있지 않은 건 "판단 불가".

| 항목 | V뱅크가 제출한 내용 |
|---|---|
| 모델 개발 | 사내 데이터팀 3명이 자체 개발 (v0.1, `L3-scorecard.md`) |
| 대안 데이터 | 제휴 통신사 요금 납부 기록, V뱅크 앱 기기 정보·접속 로그 |
| 고객 동의서 | 앱 가입 시 "서비스 개선 및 맞춤 상품 추천 목적" 동의만 받음. 신용평가 목적 문구 없음 |
| 거절 사유 | 시스템이 점수 하위 변수 2개를 자동으로 사유 코드로 생성 |
| 고객 설명 | 고객이 설명을 요청할 때 쓰는 양식·절차는 "출시 후 준비 예정" |
| 직원 설명 자료 | 없음 |
| 사람 검토 | 580~619점 구간만 심사역이 검토. 579점 이하는 자동 거절 |
| 감독 담당 | 여신심사팀장을 모델 책임자로 지정. AI 관련 교육은 아직 없음 |
| 이사회 | 프로젝트 예산만 승인. AI 위험 보고는 아직 없음 |
| 공정성 점검 | 하지 않음 |
| 영향평가 | 하지 않음 |
| 데이터 품질 | 결측치 비율만 점검. 대표성·최신성 점검 없음 |
| 정정·재산출 절차 | 자료 미제출 |
| 출시 후 모니터링 | 계획 없음 |
| 중단 기준 | 없음. 단, 기존 수기 심사 기준표는 남아 있음 |
| 데이터 제공 업체 | 통신사와 데이터 제공 계약 있음. 데이터 품질·오류 정정 조항 없음 |
| 로그 | 신청 건마다 점수, 변수 값, 모델 버전 자동 저장 |
| 로그 보관 | 3개월 후 삭제 |
| AI 기본법 사전검토 | 자료 미제출 |
