# L2 요구사항 표 — AI 신용평가 출시 심사 (V뱅크)

- 근거: L1 규제 원문 카드 (C01~C17)
- 분류: 설명 · 공정성 · 데이터 · 사람의 감독 · 모니터링 · 기록 (6분류, 총 18개)
- 작성 엔진: Claude (초안) → 리즈 판단
- 2주차 L4 실사에서 각 요구사항을 충족 / 부분 / 미충족 / 판단 불가로 평가할 예정
